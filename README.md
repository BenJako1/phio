## Windows
Clone the repository or download it as a zip file. Navigate to the directory:<br>
`cd C:\path\to\your\project`<br>
and create a virtual python environment...<br>
PowerShell:<br>
`py -m venv .venv<br>
.\.venv\Scripts\Activate.ps1`<br>
Command Line:<br>
`py -m venv .venv<br>
.venv\Scripts\activate`<br>
Install the project in editable mode:<br>
`python -m pip install -e .`
